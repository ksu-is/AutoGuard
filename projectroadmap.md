# AutoGuard Project Roadmap

## Sprint 1: Research and Planning

For my project, AutoGuard, I explored an existing Python project called Smart VIN Decoder.

**Project Link:** https://github.com/ksu-is/Smart-VIN-Decoder

### What I Learned
After reviewing the code, I learned how Python can use the requests library to communicate with the NHTSA API and retrieve vehicle information using a VIN. The program also uses functions, dictionaries, loops, and conditional statements to manage user input and store VIN history.

### Testing
I successfully ran the Smart VIN Decoder program and tested its VIN decoding feature. The program retrieved vehicle information from the NHTSA API.

### How This Relates to AutoGuard
I plan to use a similar approach to implement VIN decoding in AutoGuard. However, my project will expand on this functionality by allowing users to estimate vehicle ownership costs, track maintenance expenses, and identify potential financial risks.

### Next Steps
My next goal is to begin developing AutoGuard's basic Python structure and implement VIN decoding.
